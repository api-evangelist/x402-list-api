# x402 List API

An open, machine-readable, live-monitored directory of services that accept x402 protocol payments (HTTP 402 Payment Required). Self-described as agent-first, it exposes service listings, uptime metrics, pricing, facilitator settlement data, and rankings as JSON for autonomous agents, aggregators, and integrations.

## APIs

- **x402 List API** — Public REST API (OpenAPI 3.1) providing access to the x402 services directory, uptime, pricing, facilitator volumes, networks, stats, rankings, and change events. Free reads (rate-limited), with x402 pay-per-request metering for bulk usage. (`https://x402-list.com/api/v1`)

> Provider exposes multiple publicly reachable interfaces: a no-auth public REST API (OpenAPI 3.1, base https://x402-list.com/api/v1/; canonical spec at https://x402-list.com/openapi.json which 301-redirects to /api/v1/openapi.json), a hosted Streamable HTTP MCP server at https://mcp.x402-list.com/mcp (6 read-only tools plus a paid x402_assess_services tool), and llms.txt/llms-full.txt. A local stdio MCP variant is available via 'npx -y x402-list-mcp' but is not cataloged as an MCPServer property per guidance.
